# 🏆 SportX Homepage

A modern, responsive sports homepage designed to provide an engaging and visually appealing sports experience.

The website features live matches, sports categories, featured events, upcoming matches, and interactive UI elements with smooth animations.

## 🌐 Live Demo

👉 https://sportx-web.netlify.app

## 📸 Project Overview

This project is a frontend sports website created with a focus on:

- Modern and clean UI design
- Responsive layout
- Interactive sports sections
- Smooth animations
- Colorful and engaging visual elements
- Mobile-friendly design

## ✨ Features

- 🏠 Modern Hero Section
- ⚽ Live Matches Section
- 🏅 Sports Categories
- 🎯 Featured Events
- 📅 Upcoming Matches
- 🔴 Live Match Indicators
- ▶️ Watch Live Button
- 🔔 Match Reminder Button
- ✨ Animated UI Elements
- 📱 Responsive Design
- 🎨 Gradient backgrounds and interactive cards
- 🖥️ Desktop and mobile friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons
